# 🎮 TriviaFi

> Play trivia. Win USDC. Fully on-chain.

TriviaFi is a Web3 trivia game where players compete in real-time and earn **USDC rewards**.
Built on Arc Testnet — expanding to multi-chain soon.

---

## ⚡ Features

* 🧠 Real-time trivia gameplay
* 💰 USDC prize pools
* 🏆 Live leaderboards
* 🔐 Wallet + Google authentication
* ⛓ On-chain score verification
* 🤖 Automated game creation agent

## 🚀 Getting Started

### 1. Clone repo

```bash
git clone https://github.com/YOUR_USERNAME/triviafi.git
cd triviafi
```

### 2. Install backend

```bash
cd backend
npm install
```

### 3. Setup environment

```bash
cp .env.example .env
```

Fill in your environment variables.

### 4. Run backend

```bash
node server.js
```

### 5. Run frontend

Open:

```bash
frontend/index.html
```
